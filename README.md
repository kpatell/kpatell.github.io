# kpatell.github.io

Personal site for Krishan Patel, live at [kpatell.github.io](https://kpatell.github.io).

## Stack

React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Development

```bash
npm install
npm run dev      # local dev server (localhost:5173)
npm run build    # typecheck + production build
npm run preview  # preview production build
```

Pushes to `main` deploy automatically to GitHub Pages via `.github/workflows/deploy.yml`.
